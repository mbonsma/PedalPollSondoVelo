# Pedal Poll / Sondo Vélo 2022 and 2023 analysis

This repo contains the code and documentation for analysis of the 2022 and 2023 Pedal Poll / Sondo Vélo data.

The 2021 results can be found [here](https://velocanadabikes.org/pedalpoll/pedal-poll-sondo-velo-2021-results/) and the associated academic paper is [here](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4000804).

To-do items can be found in the [Issues](https://github.com/mbonsma/PedalPollSondoVelo/issues) tab.
